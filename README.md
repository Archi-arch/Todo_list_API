# My To-Do API (.NET 10)

Сучасний, швидкий та оптимізований бекенд для таск-менеджера, написаний на C# з використанням **Minimal API**. Проєкт повністю докерізований та готовий до розгортання в будь-якому середовищі.

## 🚀 Технологічний стек
* **Платформа:** .NET 10
* **База даних:** SQLite / Entity Framework Core
* **Контейнеризація:** Docker
* **Архітектурні патерни:** DTO (Data Transfer Object), DRY Валідація, М'яке видалення

## ✨ Головні фічі
* **Many-to-Many зв'язки:** Завдання можуть мати декілька категорій одночасно.
* **Повнотекстовий пошук:** Динамічна фільтрація тасок за назвою через Query-параметри (`?search=...`).
* **Пагінація:** Ефективна робота з великими списками завдань за допомогою `.Skip()` та `.Take()`. За замовчуванням виводиться по 15 тасок на сторінку.
* **Soft Delete (М'яке видалення):** При видаленні завдання воно не стирається з бази назавжди, а маркується прапорцем `IsDeleted` і переміщується в кошик.
* **Автоматичні міграції:** При старті програми всередині Docker, EF Core самостійно перевіряє стан БД і накочує свіжі міграції.
